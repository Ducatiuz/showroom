# Ducati Uzbekistan — Showroom

Каталог мотоциклов в наличии, байков под заказ и экипировки салона Ducati Uzbekistan (Tashkent City).
Языки: RU / UZ / EN.

- `index.html` — приложение (данные каталога внутри, в блоке `STOCK`)
- `img/` — фото мотоциклов

Внутренние данные (себестоимость, дни на складе, VIN) в репозиторий не попадают.
